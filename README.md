# Ride-Sharing System

A Java-based ride-sharing application developed for the **CSC 212 – Data Structures** course at King Saud University.

## Project Overview

The system manages riders, drivers, and ride reservations using custom linked-list data structures.

### Key Features
- Manage rider and driver information.
- Schedule private and shared rides.
- Search and list riders, drivers, and rides.
- Detect scheduling conflicts.
- Maintain ride histories and handle ride cancellations.
- Load data from CSV files.
